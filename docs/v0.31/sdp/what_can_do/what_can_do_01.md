# 不写代码，你能做出哪些模块?

SDP 已经为你预制了 6 种最常见的后台模块模板。你只需要在 Excel 里“告诉”平台表结构和菜单，平台就生成对应模块。

![](/excel_intro/module_intro_54.png)

---

## 6 种模块快速选型表

打开文档前先回答一个问题：**我的页面和数据长什么样?**

| 你的场景 | 用 | 关键能力 |
| --- | --- | --- |
| 单表 + 新建/编辑(员工档案、商品管理) | [m1](#m1-数据列表采集) | 最常用、覆盖 80% 业务 |
| 图片 / 视频 / 音频展示(素材库、相册) | [m2](#m2-媒体列表采集) | 在 m1 基础上换卡片渲染 |
| 一张主表带多张子表(订单 + 商品明细) | [m3](#m3-主子表展示采集) | 主表 + 子表嵌套编辑 |
| 一对多关联(用户 + 角色、商品 + 标签) | [m4](#m4-关联表展示1) | 主表带关联表设置 |
| 树状数据(菜单维护、组织机构) | [m5](#m5-树状数据采集) | 左侧树 + 表单 |
| 左侧树 + 右侧列表(部门下员工) | [m6](#m6-树状数据数据列表) | m5 + m1 组合 |

> 💡 选错了也别担心 —— m2 / m3 / m4 / m6 都是在 m1 的基础上多配几项，理解了 m1 其他都顺。

---

## 一. 概述

无需通过编码，仅编写 Excel 模版文件，并通过敏捷开发平台进行模块构建，即可完成下列类型的页面和模块搭建。可供需求 / 设计、开发人员使用。

- **Excel 编写说明**：[→](/sdp/build_by_excel/1-sheet_table.html)
- **数据库层面**：完成下面 6 种配置，就已具备"基于数据表及其关系"处理数据的基础能力
  - **单表维护**：普通表(m1)、树状表(m5)
  - **主子表维护**：如主表"人员基本信息表"、子表"人员工作履历表"(m3)
  - **一对一、一对多关系**：主表中含关联表主键(m4)、关联关系在第三张表中(m4)

**谁可以用?**

- **需求 / 设计人员**：对接客户需求，迅速产出原型图，减少原型图设计时间，并同步生成部分设计文档
- **开发人员**：初始化系统搭建，基础模块搭建，同步完成数据库设计

## 二. 6 种模块详解

### m1. 数据列表 + 采集 {#m1-数据列表采集}

#### 这是什么 / 用在哪

- 一张表 + 一个表单 = 后台里 80% 的页面
- 典型场景：员工档案、商品管理、订单列表、客户管理

#### 配置流程

**基础三件套(必选)**

1. [配置菜单](/sdp/build_by_excel/4-sheet_menu.html)
1. [配置表](/sdp/build_by_excel/1-sheet_table.html)
1. [配置模块(列表 / 表单 / 工具栏属性)](/sdp/build_by_excel/2-sheet_module.html)

**列表(可选)**

1. [配置列表项](/sdp/build_by_excel/3-sheet_dict.html#列表项)
1. [配置筛选项](/sdp/build_by_excel/3-sheet_dict.html#筛选项)
1. [配置列表默认操作列(编辑 / 删除 / 详情)](/sdp/build_by_excel/2-sheet_module.html#列编辑列删除列详情)

**表单(可选)**

1. [配置表单项](/sdp/build_by_excel/3-sheet_dict.html#表单项)

**自定义(可选，需要写代码)**

1. [配置自定义按钮(工具栏或列表列)](/sdp/build_by_excel/2-sheet_module.html#自定义按钮)`💻需要配合自定义开发`

#### 展示 & 使用

**查列表**

- 单表查询、多表关联查询、自定义 SQL / 视图查询
- 码表转换：列表中把"1"显示成"男"、"女"
- 格式化数据：日期、数值等不同展示方式
- 统计项：合计、最大值、最小值、平均值
- 接口来源：可使用预制接口，也可配置自定义接口 `💻需要配合自定义开发`
- 展示列表默认操作、及自定义操作列 `💻需要配合自定义开发`
- 列表展示项：序号、边框、首选项(Radio / Checkbox / 无)、列宽、固定列、隐藏、排序、合并列头、开启标识、主键标识、对齐方式、序列
- 展示筛选列，如：类型、类型扩展参数、序列、名称、位置、占位符、布局

**查详情**

- 单表查询、多表关联查询

**工具栏**

- 默认按钮：新增、编辑、删除、批量、导入、导出
- 自定义按钮 `💻需要配合自定义开发`

**数据维护**

- 删除：支持单一主键 + 联合主键
- 新建 / 修改(表单)：
  - **输入控件**(15+)：Input、InputNumber、Select、DatePicker、Radio、Checkbox、TextArea、GroupTitle、TreeSelect、Upload、UploadVideo、UploadAudio、UploadPicture、RichTextEditor、MarkdownEditor
  - **校验规则**(20+)：必录、数字、字母、电话、邮件、身份证、中文、日期、数值范围 /- /+- /+0 /-0、NUMBER(15，5)、VARCHAR2(6)、长度 2\~10、长度=21、yyyy-MM-dd、yyyyMM、`[string](自定义方法名)` `💻需要配合自定义开发`
  - **码表驱动**：Select / Radio / Checkbox / TreeSelect 自动取码表
  - **格式化**：根据字段类别展示
  - **公式**：表单项自动计算
  - **布局**：按配置宽度展示
  - **只读 / 隐藏 / 序列 / 扩展参数**：按字段配置
  - **事件**：失焦、聚焦、值改变、查询 `💻需要配合自定义开发`

**数据导入**

- 通过 Excel 批量导入数据

### m2. 媒体列表 + 采集 {#m2-媒体列表采集}

#### 这是什么 / 用在哪

- 在 m1 的基础上，把列表渲染换成"图片卡片"或"列表"，适合素材 / 视频 / 音频
- 典型场景：媒体库、相册、素材中心、视频管理

#### 与 m1 的差异

- 多了"列表扩展 = card"配置
- 多了"列表项格式化列 = media：*"配置(图片 / 视频 / 标题 / 描述)
- 多了"表单 = MediaLibrary"控件

#### 配置流程

**基础三件套(必选)** —— 与 m1 相同

1. [配置菜单](/sdp/build_by_excel/4-sheet_menu.html)
1. [配置表](/sdp/build_by_excel/1-sheet_table.html)
1. [配置模块列表属性](/sdp/build_by_excel/2-sheet_module.html#列表)

**媒体特有(必选)**

1. [配置列表媒体形态](/sdp/build_by_excel/2-sheet_module.html#列表扩展)`★关键项`
1. [配置列表项，媒体格式化列(图片 / 视频 / 标题 / 说明 / 预览地址可匹配任意字段)](/sdp/build_by_excel/3-sheet_dict.html#列表项格式化列)`★关键项`

**筛选 / 表单 / 工具栏** —— 与 m1 相同

#### 展示 & 使用

- 切换媒体卡片形态、列表形态
- 预览图片、视音频文件
- 涵盖 [m1 的全部功能](#m1-数据列表采集)
- 支持自定义卡片布局及渲染 `💻需要配合自定义开发`

## 四. 几个常见的踩坑提醒

1. **不要先选 m 几，先想清楚数据关系**
   - 单表 → m1;有父子 → m5;有主子 → m3;有一对多 → m4
2. **m2 不是"另一种列表"，而是 m1 的"列表扩展"**
   - 核心还是 m1，只是把列表渲染换成卡片，字段、按钮、校验都一样
3. **m3 / m4 / m6 都是 m1 的组合**
   - 理解了 m1，其他都只是"多配几张表 / 几个关联字段"
4. **配置时按"基础 → 列表 → 表单 → 自定义"顺序来**
   - 不要跳着配，容易漏字段
