
# 前端开发自查

## 列表
* 对齐方式：数字居右，操作列（含开关）居中，其他居左。特例：‘’数字/数字‘’格式居右。
* 数字：千分位展示，金额2位小数，汇率5位、税率2位小数、数量4位。
* 列宽：固定字数或可以确定字数的列（如码表、日期）按照其最多字数设置。
* 列宽：除特殊要求，显示内容不允许折行，超出设定单元格或表格x轴宽度，显示省略符。
* 列宽：能够确定字数的列，需要显示完整，内容不要折行。
* 列宽：测试1280分辨率，列不能折行。
* 列宽：如果数据列较少，至少有一列列宽宽度是自适应，即不设置宽度，防止列宽等比放大。
* 列表中单位，写到表头。
* Mock数据完整，且真实数据，不要出现111、222、aaa、bbb。
* 排序：需要有默认排序规则。

## 筛选条件
* 两个及以下筛选条件的，放到工具栏所在行。
* 列头筛选，如果只有两种状态，则用radio类型，且增加全部；两种以上状态，且10个以内，采用Checkbox；其他或特殊码表筛选，按需求说明开发。
* 列排序、列筛选：严格按照需求文档，如果和上述规范冲突，及时与需求协商调整。

## 其他
* 除列表外其他业务数据，如表单，mock数据需要完整且真实有效。
* 弹窗标题与开启按钮应对应。
* 提示信息标点符号，末尾统一采用句号。
* 滚动条，不能同时有列表内滚动条与浏览器滚动条。
* 测试1280px分辨率。
* 工具栏按钮顺序按照需要开发。
* 弹窗按钮问题，取消default按钮左，确定primary按钮右。
