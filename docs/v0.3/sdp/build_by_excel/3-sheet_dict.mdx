### 参数取值说明
| 参数 | 可选值 | 对应api参数 | 说明 |
| --- | --- | --- | --- |
| 1.分组标题 | | | 数据字典中文及英文名称，格式：`中文名 英文名` |
| 2.主表字段 | | grid_columns[].dataIndex & *_items[].name | 数据库建表标识，用于列表及表单展示中的基于数据库主表的字段，格式：表名.字段名 |
| 3.关联表字段 | | grid_columns[].dataIndex & *_items[].name | 数据库建表标识，用于列表及表单展示中的基于数据库从表的字段，格式：表名.字段名 |
| 4.字段中文名 | | grid_columns[].title & *_items[].label | 数据库建表标识，用于页面展示：列表列标题，表单项名称，筛选项名称 |
| 5.数据类型 | | | 数据库建表标识，数据类型 |
| 6.键 | `主键` | | 数据库建表标识，键标识 |
| 7.默认值 | | | 数据库建表标识，默认值标识 |
| 8.非空 | `N` | | 数据库建表标识，非空标识 |
| 9.关联字段表达式 | | | 数据库查询标识 |
| 10.字段过滤器 | | | 预留字段 |
#### 参数2.主表字段 <Badge text="2024-10-17" type="tip" />
* 无需书写表名，名表通过当前数据字典查找**表管理sheet**页获取
* 字段为小写格式
#### 参数3.关联表字段 <Badge text="2024-10-17" type="tip" />
* 需按需写表名，格式为**表明.字段名**，如查询申报表的出口商品代码，则标记为**mts_tssb.cksp_dm**
* 字段为小写格式
#### 参数5.数据类型
**示例**
* 表关联：`varchar(32)`
* 表关联：`char(5)`
* 表关联：`datetime`
* 表关联：`decimal(18,6)`
* 表关联：`char(5)`
#### 参数9.关联字段表达式 <Badge text="2024-10-17" type="tip" />
**示例**
* 表关联：`left join mts_tssb.ssq`
* 字段重命名：`ext:sbny`，接口中，重命名字段名称
* 关联字段：`ref:gnqyfs_dm`，多用于码表中文所需要的关联字段
* 字段初始排序：`order:asc`，标识当前字段用于列表展示时的初始排序，且标识排序规则
* 分词 <Badge text="2024-11-26" type="tip" />：`fc:2|fc_content1|0`，`|`号分割3个参数依次代表分词`分词字典类别`、`来源字段`、`分词规则`

### 参数取值说明
| 参数 | 默认值 | 可选值 | 对应api参数 |
| --- | --- | --- | --- |
| 1.列表项开启标识 | | `1` | - |
| 2.列表项主键标识 | | `1` | - |
| 3.列表项对齐方式 | `L` | `L` \| `R` \| `C` | grid_columns[].align |
| 4.列表项列宽 | | number |  grid_columns[].width |
| 5.列表项固定列 | | `L` \| `R` | grid_columns[].fixed |
| 6.列表项隐藏标识 | | `1` | grid_columns[].hidden |
| 7.列表项超出隐藏 | | `1` | grid_columns[].ellipsis |
| 8.列表项格式化列 | | `YYYY-MM-DD HH:mm:ss` \| `0,0.00` \| string (自定义方法的名称) | grid_columns[].render |
| 9.列表项排序开关 | | `1` \| `mul` | grid_columns[].sorter |
| 10.列表项序列 | | number | - |
| 11.列表项合并列头 | | number | grid_columns[].children |
| 12.列表项统计 | | `1` \| `min` \| `max` \| `avg` \| `sum` | grid_columns[].min2/max2/avg2/sum2 |
#### 参数1.列表项开启标识
标识当前字段是否用于列表中。
#### 参数2.列表项主键标识
标识当前字段为列表主键。如果需要对当前行数据进行操作，如单选、多选、编辑当前行数据，则必须开启。
#### 参数6.列表项隐藏标识
一般用于配置列表主键时开启，开启后当前字段不显示在页面中。
#### 参数8.列表项格式化列
* 日期格式示例：**YYYY-MM-DD HH:mm:ss**
* 数值格式示例：**0,0.00**
* 自定义格式化：**formatXXX** (自定义方法的名称)
* 卡片格式化  <Badge text="2024-11-19" type="tip" /> \
  卡片图片地址：`media:imagepath` \
  卡片视频地址：`media:videopath` \
  卡片标题：`media:title` \
  卡片描述：`media:description` \
![](/excel_intro/module_intro_21.png)
* 树格式化  <Badge text="2024-12-12" type="tip" /> \
  树结构数据id：`tree:key` \
  树结构数据名称：`tree:title` \
  树结构数据父级id：`tree:parent_key`
* 一对多关系数据  <Badge text="2025-01-06" type="tip" /> \
  格式：`leaf:模块名&子列表显示标题字段`，如：`leaf:eg_m_staff_education&staff_name`
* json数据弹窗展示示例：`json` <Badge text="2025-01-01" type="tip" />
* copy图标展示及快速复制示例：`copy` <Badge text="2025-01-01" type="tip" />
* color颜色标签渲染示例：`color` <Badge text="2025-05-29" type="tip" />
* RichText数据弹窗展示示例：`RichText` <Badge text="2025-09-23" type="tip" />
* Markdown数据弹窗展示示例：`MarkdownEditor` <Badge text="2025-09-23" type="tip" />
* 一对多关系数据1  <Badge text="2025-05-29" type="tip" /> \
  格式：`rel:关联模块名&关联模块名称字段`，如：`rel:eg_m_tag&tag_name`
* 一对多关系数据2  <Badge text="2025-05-29" type="tip" /> \
  格式：`rel:关联模块名&关联模块名称字段&关联表模块名`，如：`rel2:eg_m_honor&honor_name&eg_m_staff_honor_ref`
* switch  <Badge text="2025-11-28" type="tip" /> \
  格式：`switch:开启值,关闭值`，如：`switch:1,0`。同步调用表单的编辑接口进行数据处理。
* timeEasyRead  <Badge text="2025-11-28" type="tip" /> \
  格式：`timeEasyRead`。将毫秒数转为xx毫秒、xx秒或xx分。
* timeEasyRead  <Badge text="2025-11-28" type="tip" /> \
  格式：`tagColor`，将数据用Tag包装，需配合自定义开发，如：
  ```ts
  customerIconMapping.response_code_tag_color = [
    {code: '200', color: myUtil.theme.getColor({type: 'success'})},
    {code: 'ELSE', color: myUtil.theme.getColor({type: 'error'})},
  ]
  ```
#### 参数9.列表项排序开关
如填写`mul`，表示开启多列排序
#### 参数10.列表项序列
如配置列表项序列数值，则列表列展示顺序通过配置的数值由小到大排列。
#### 参数12.列表项统计
用于对数值字段的统计，按需配置最大、最小、合计、平均，如填写1，则表示统计全部4项信息。

* 日期格式 **YYYY-MM-DD HH:mm:ss**

#### 参数5.表单项类型扩展参数
* `maxCount`：Upload、UploadVideo、UploadAudio、UploadPicture类型时，可配置如：`maxCount=3`，标识最大上传数量为3
* `multiple`：Select类型时，可配置，标识多选类型
* `showTime` <Badge text="2024-11-19" type="tip" />：日历组件中展示时间，通常需要与表单项格式化同步使用，如设置`YYYY-MM-DD HH:mm:ss`
* `formula`<Badge text="2024-11-26" type="tip" />: 当前项目公式，如填写：`formula:{flp1}+{flp2}`。表示当前表单项目取值来自flp1、flp2字段之和。表单中用到项目需要`大括号`包裹
