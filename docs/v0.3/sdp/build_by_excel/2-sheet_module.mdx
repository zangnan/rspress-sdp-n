| 参数 | 默认值 | 可选值 | 对应api参数 |
| --- | --- | --- | --- |
| 1.工具栏增加 | | `1` | toolbar_default.add |
| 2.工具栏删除 | | `1` | toolbar_default.delete |
| 3.工具栏编辑 | | `1` | toolbar_default.edit |
| 4.工具栏导入 | | `1` | toolbar_default.upload |
| 5.工具栏导出 | | `1` \| `2`\| `pdf` | toolbar_default.download & toolbar_default.download_config & toolbar_default.download_pdf |

| 8.工具栏刷新 | | `1` | toolbar_default.reload |
| 9.工具栏筛选 | | `1` | toolbar_default.advanced_filter |
#### 参数5.工具栏导出 <Badge text="2025-2-13" type="tip" />
如果设置为包含`2`，则为后端导出数据。如：填写`1,pdf`表示开启Excel前端导出数据和PDF导出。

| 参数 | 默认值 | 可选值 | 对应api参数 |

| 1.表单布局 | `horizontal` | `horizontal` \| `vertical` \| `2` \| `3` \| `4` | form_layout_type |
