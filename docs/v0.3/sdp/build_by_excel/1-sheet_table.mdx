## 填写说明
| 参数 | 可选值 | 说明 |
| --- | --- | --- |
| 1.表分组标题 | | 表名称，格式：`表中文名 表英文名` |
| 2.字段 | |  数据库建表标识，字段英文名 |
| 3.字段中文名 | |  数据库建表标识，字段中文名 |
| [4.数据类型](/sdp/build_by_excel/1-sheet_table.html#数据类型示例) | | 数据库建表标识，数据类型 |
| 5.键 | `p_key` | 数据库建表标识，键标识 |
| 6.默认值 | | 数据库建表标识，默认值标识 |
| 7.非空 | `Y` | 数据库建表标识，非空标识 |
| 8.备注 | | |

### 数据类型示例

* decimal(8,0)
