## 填写说明

* 参数取值说明

| 参数 | 可选值 | 说明 |
| --- | --- | --- |
| 表分组标题 | | 表名称，格式：`表中文名 表英文名` |
| 字段 | |  数据库建表标识，字段英文名 |
| 字段中文名 | |  数据库建表标识，字段中文名 |
| [数据类型](/rspress-sdp-n/sdp/build_by_excel/1-sheet_table.md#数据类型示例) | | 数据库建表标识，数据类型 |
| 键 | `p_key` | 数据库建表标识，键标识 |
| 默认值 | | 数据库建表标识，默认值标识 |
| 非空 | `Y` | 数据库建表标识，非空标识 |
| 备注 | | |

### 数据类型示例

* varchar(32)
* datetime
* decimal(8,0)
* char(2)
* decimal(18,2)
* long
