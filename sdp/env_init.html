    #开发环境搭建

    1. nodejs: 24.14.0+
      • 安装 node-v24.14.0
      • 查看版本：node -v
    2. yarn: 1.22.22+
      • npm install --global yarn
      • 查看版本：yarn -v

    #下载代码并安装依赖

    #配置文件调整

    • config.ts为项目的配置文件，开发模式中如果需要调整，则在config.dev.ts增加对应配置。
    • API_URL_BASE_NODE：后端接口根目录地址

    #启动项目 npm start

    #系统初始化

    • http://localhost:3001/easy_dev_dc/init
    • 一键初始化系统基础构建：创建系统默认表及导入系统默认表初始数据。
      1. ) 初始化基本表结构
      2. ) 初始化系统基本信息
    • 自定义初始化：下载模板，按需调整表结构及数据，依次完成初始化。

    #登录

    • http://localhost:3001/user/login
    • 默认用户名/密码：admin/ddit@1234

    • 菜单中进入敏捷开发 - 系统构建模块，构建业务系统，参照Excel构建

    #项目发布

    #配置文件调整

    • 调整根目录，config.ts文件中，变更ddittoolV0.2为所发布的根目录。
    let proBase = process.env.NODE_ENV === 'production' ? 'ddittoolV0.2' : '';

    #打包

    • 项目安装目录下执行 npm run build

    #部署至服务器

    • 打包后的dist文件夹变更名称为上述根目录名称后部署到服务器中。

    #执行

    • 如本地部署，端口为8080，执行下列地址可进行初始化及登录操作。
    • http://localhost:8080/ddittoolV0.2/#/ddittoolV0.2/easy_dev_dc/init
    • http://localhost:8080/ddittoolV0.2/#/ddittoolV0.2/user/login
